## 🎯 Solarpunk Core CSS Classes

### 🔮 Frosted Glass & Border Brackets
- `glass-hud` — Frosted glass panel with neon border glow.
- `hud-corner` — Decorative cybernetic corner brackets.

### 🧠 BCI Cognitive HUD Adaptations
- `neon-glow-gold` — Glowing post-quantum/quantum elements.
- `tech-mono` — JetBrains Mono monospace font for telemetry arrays.
- `low-load-panel` — Flat, minimal CSS class activated during high stress.

## 🧬 CRISPR & SNN Visual Elements

### 1. PCR Alignment Highlights
- `aligned-match` — Glowing green background for target genomic matches.
- `aligned-mismatch` — Pulsing yellow text highlighting PCR gaps.

### 2. SNN Spiking telemetry
- `snn-spike` — Small glowing canvas dots depicting biological neuron action potentials.
- `outage-alert-banner` — Pulsing red banner indicating LoRaWAN buffer queue holds.
